# Pocket Stickers — releases

Signed APKs of Pocket Stickers, an Android app that keeps WhatsApp sticker packs, and the list of
what changed in each version. The source code is not here.

Each version is a GitHub release whose tag is `v<versionName>-<versionCode>`, with the APK attached
and the changes in its notes. The app itself reads this repository's latest release to offer
updates; no key or account is needed.

To install by hand: download the APK from the latest release and open it on the phone. Android
asks to allow installing from that app, and Play Protect may ask to scan it.
